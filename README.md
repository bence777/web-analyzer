# Web Audit

A Web Audit egy egyszerű Chrome böngészőbővítmény, amivel gyorsan elemezheted az aktuálisan megnyitott weboldalt SEO, UX, tartalom, linkek, képek, technikai állapot, sebesség, akadálymentesítés és alap biztonsági szempontok alapján.

## Funkciók

- SEO audit
- Tartalmi elemzés
- UX ellenőrzés
- Link audit
- Kép optimalizálási javaslatok
- Technikai audit
- Performance becslés
- Accessibility / akadálymentesítés ellenőrzés
- Alap biztonsági vizsgálat
- Összesített pontszám
- Top javítási javaslatok
- Riport másolása vágólapra

## Fontos megjegyzés

Ez az eszköz gyors, böngészőből futó becslést ad az oldal állapotáról.  
Nem helyettesíti a Lighthouse, PageSpeed Insights vagy manuális szakmai audit eredményeit, de jó kiindulópont a hibák és fejlesztési lehetőségek gyors megtalálásához.
